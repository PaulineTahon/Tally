# Share, redesigned: a QR code for every Tally form

This is my clickable prototype for the Tally designer assignment. Task 1 asked me to simplify the Share tab and add a QR code. Task 2 asked for visuals announcing it.

**Live prototype:** https://paulinetahon.github.io/Tally/
**Announcement visuals:** https://paulinetahon.github.io/Tally/visuals/

## The idea

People don't really want to "share". They want enough of the right responses, fast. So instead of one Copy button surrounded by unrelated cards, I built the Share tab around the link and the places people share it, with the QR code as one more format of that same link.

**Simple is my proposal**, and it's what the prototype opens on: the link with Copy and a QR code button next to it, the link preview, and Embed. **Split** (`?variant=split`) shows how I'd add tracked links on top of it as a next step. Tabs, Rows, Tiles and Jobs are explorations I made on the way.

I started with the quick win, then the bigger bet:

1. **A share sheet right after Publish, the first time.** The link and Copy always sit on top, with Use custom domain under them. Then Link preview: a compact preview card, the way your link shows up in a chat or a post, with Customize preview under it. The preview applies to every link and code, whatever the ref. Below it, "More ways to share" has three tabs: QR Code, Social and Embed. On the desktop Share tab page the link, Copy and Use custom domain share the card's width (520px at most, the width of a real link preview) and left edge, and the tabs hug their labels. Every section keeps one rhythm, in the sheet and on the page, in all three versions: 8px from a label to its content, 8px from the content to its text action, 24px to the next label. Every section title in Share uses one style, 14px bold in the text colour, like Tally's labels: Share link, Link preview, More ways to share, Embed, and Links and QR codes on the tracking page. Share link used to be a bigger 18px heading on the page; it now matches Embed, and the sheet has the same Share link title over the link, so the page and the sheet read the same. Add your logo on a code's page uses the same label style as Image, Title and Description in Customize preview. Every item uses one set of spacing in every version, in the sheet, the modal and on the page. Rows (codes, links, socials, the tracking row, Add another, the Rows entries) have 8px inside on every side, 12px between their parts, 4px between their trailing buttons, and are at least 40px tall (44px on a phone). Cards with a border (the link preview, the Tiles) have 12px inside and 12px between their parts. Grey boxes (the embed code, your new link) have 8px by 12px. Tiles (the social marks, the embed layouts) have 8px from the picture to its label and 12px between tiles. Create a template isn't part of sharing: it lives in the More actions menu (...) next to the form title. The first publish always opens on QR Code; after that the sheet remembers the tab you used last. The sheet eases to the height of each tab, so short tabs never leave an empty gap and Done glides instead of jumping. On a phone it's a bottom sheet with a Share button that opens the native share sheet, and the card and tabs stay compact so your QR code is in view without scrolling. Republishing a form that already has responses shows a short toast with a Share button instead, so the sheet doesn't get in the way.
2. **A calm sheet, actions in context.** Copy is the only black button (on a phone, Share is, and Copy is outlined next to it). Embed is the exception: where Copy isn't on screen (the Embed tab in the Split and Simple sheets, the Embed view in Rows, Tiles and Jobs, and the full Embed page), Copy code is the black button. Where Copy is on screen too (the Embed section on the Split and Simple Share tab pages and the Embed tab in Tabs), Copy code stays outlined. Copy code is always the same size as the link's Copy: 36px high, 15px semibold, 16px icon, 8px corners, and 44px on a phone. The link options live where they apply: Use custom domain, under the link like in Tally today (Edit custom domain once one is saved), opens "Link ending and domain", and Customize preview, right under the preview card, opens the preview editor (title, description, image). Upload your own image and Replace and Remove appear next to its thumbnail; Remove goes back to the default image. Nothing is kept until Save. There is no pencil in the link field, so the ending never looks editable without a domain. On the desktop Share tab page, everything that opens (Use custom domain, Customize preview, a code's page, and in Rows and Tiles each way to share) opens in a centred modal with the same content, with Back in its header one level down. Each one takes over the whole sheet: the link, the card and the tabs step aside, the header shows a Back arrow and the view title, and Back takes you to the tab you came from. Back never saves and never asks: it puts things back the way they were saved. Escape still closes the whole sheet. In a detail view the save button is the one black button (Save on Pro, Upgrade to Save on Free); Copy isn't on screen there. On Free, Save reads Upgrade to Save and opens the upgrade pop-up, a copy of the plans pop-up on Tally today (Pro and Business, pay monthly or yearly, at tally.so/pricing prices). Upgrade there and you land back in the same view, with your values kept and Save ready. Use custom domain and every preview get the same quiet text action under them, like Tally's own Use custom domain: grey underlined text with the Pro badge right after it, no icon, and a 44px tap target on a phone. That's Customize preview under the card, Customize QR code under the codes and Customize embed right of Copy code on the same line, all the same text button (Customize embed has no Pro badge, embedding is free). Add another code stays a row with its + icon, under Customize QR code. Looking at your preview is free. Social starts with one line, "We tag each link so you can see where responses come from.", then one borderless row per place: WhatsApp, Instagram, Facebook, LinkedIn, X and Email. Every item copies, and never opens the app or the site: Copy link copies that place's tagged link (with its ref, like ?ref=whatsapp), says Copied right in the row and shows an alert at the bottom. That goes for WhatsApp and Email too, in every version and every Social layout. Embed shows Standard, Popup and Full page as three cards on one row (180px wide on the full-width Share tab page, 120px in the sheet, in a modal and on a phone), plus one line linking to Tally's guide on how embedding works. None of them is picked to start with, so there's no code yet. Pick one and its whole real snippet opens under the cards (they stay where they are) in a short grey box, with Copy code and Customize embed under it; pick another and the code switches. The box (520px at most on the full-width page, like the link field) scrolls, with no fade: by wheel, trackpad or touch, or with the arrow keys once you tab to it (it has a focus ring and reads as Embed code). Copy code copies it (with an alert), or Customize embed opens Tally's full Embed page with that layout already chosen, with its options on the left and a live preview of your form on the right, where the popup really opens. Its Get the code shows the snippet on the dark page, with the code and a black Copy code on a white card. Close brings you back to the Embed tab. Embedding is free on Tally, so Customize embed has no Pro badge. A custom ending lives on your own domain (Pro), as an extra address: tally.so/r/KpYalV always keeps working, and every QR code points there, so printed codes never break. The view starts with just Custom domain; once you type one, Link ending opens under it, already filled in with the form's title as a slug (Community picnic RSVP gives community-picnic-rsvp), and you can change it. As you type, the view shows the full new link. Change a custom ending you had already saved and it tells you that custom links you've already shared stop working, next to the line that printed codes keep working.
3. **A plain black QR code, print-ready by default.** Black on white, in a rounded style: every module is its own round dot, never merged, and the corner eyes keep their square shape with rounded corners. A white Tally asterisk sits on a small black rounded tile in the middle, on every plan. The same style is used everywhere: on screen, in the PNG, SVG and PDF, in Insights and in every visual. No other branding. There's no colour picker: codes stay black so they're easy to scan, and the SVG is there for anyone who wants to recolour it. The one personal touch is a logo (Pro), which replaces the asterisk tile. The logo controls show straight away on the code's own page, 24px under Download, with no link to open first: Add your logo with its Pro badge on the label, "Replaces the Tally mark on all your QR codes.", and Upload, Replace and Remove. The logo is the only thing to customize. Customize QR code under the list of codes opens a code's page scrolled to the logo, with focus on it. On Free you can still try it: the Pro badge is on the label before you upload, the logo shows in the code right away, and while it's in, the black button is Upgrade to download (outlined in the QR Code tab, where Copy stays the black one), with Download without logo next to it. Upgrade to download opens the plans pop-up. Upgrade and you're back on the same page with your logo and a normal Download; remove the logo and the outlined Download PNG comes back. One plain line with the form's tally.so link always sits under the code, on screen and in every download. Download PNG saves at print size on a computer (Save image on a phone, which opens the system share sheet). The download just happens, with no animation on the button or the code, and an alert at the bottom. On the code's own page it's a split button, the same size as Copy (36px high, 44px on a phone, with the dropdown part a square of the same height), with SVG and PDF in a dropdown that opens above the sheet. A list of codes stays light instead: each row ends with Download, an outlined button with its icon and label like a link row's Copy (it saves a PNG, with a Download PNG tooltip), and ⋮, whose menu has Download SVG and Download PDF, then a divider and Remove on codes you made. They're 44px tap targets on a phone, and they never open the code. On the code's own page, where Copy isn't on screen, it's the black button. The code, its link and Download read as one group, with Download 16px under the link. Then 24px, and the logo. Error correction is level H, so the mark never stops it scanning. Every code opens tally.so/r/ with the form's ID and a `?ref` tag, never a custom domain or ending, so printed codes keep working whatever you change. Every alert (downloads, copies, saved changes) shows in the same place: at the bottom of the screen, above the sheet's footer when it has one, clear of the prototype bar and the phone's safe area. A download alert clears when you switch tab or view.
4. **One code, ready to go.** The QR Code tab starts with one line, "Print it or add it to slides. Responses are tagged, see them in Insights." (Insights is a link in Tally's link blue that opens Insights and lights up the QR rows in Sources), then each code as a list item, like Tally's list rows: a QR code icon in the text colour (no tile), its name in bold with its ?ref= in grey under it, then Download and ⋮ (the scannable code is on the code's own page and in downloads). Click anywhere on the row to open the code's own page with the big code; Download on the row just downloads. Add another code, for free, for each place you use it: each new code shows right away as its own row under Your QR Code, with its own ref (qr-poster, qr-flyer), and its results show in Insights. Every code has a More options button (⋮) after its Download icon, with Download SVG and Download PDF; on codes you made it also has Remove, under a divider: it takes the code out of Share at once, with Undo in the alert. The code still works and its responses stay tagged and counted in Insights. Your QR Code can't be removed. There is one Customize QR code under the codes: the logo is one setting for the whole form, used by every code on screen, in downloads and in Insights. The code's own page has Back and its title in the header, a bigger code with its link line, the same Download, and the logo. The tagging is said once, on the tab. Counts live in Insights only. Insights keeps every QR code in Sources at 0 visits too, so a new code never seems to go missing. You only ever see the names; the `?ref` tag stays in the link itself.
5. **Sources in Insights.** The Sources panel on the Insights tab lists your form's QR code and each extra code as its own row, by name, next to the referrers, with a Submissions column. This is the part I'd push for most: it turns sharing into a loop.

## What to try

- **Publish** in the editor and watch the share sheet open. Hit Copy and see it confirm in place.
- The sheet opens on **QR Code**. Download your code, open the format menu for SVG or PDF, then click the code to open its page and add your logo. Scan it with your phone. Then hit **Customize preview** under the preview card, change the title, go Back and see the card follow.
- Click **Add another code**, add one for a place and download it. See it in Insights.
- In **Social**, copy a link for Instagram or WhatsApp: each one carries its own tag, so Insights shows where responses came from.
- Hit **Use custom domain** under the link, add a domain and an ending, and watch the new link build as you type. Pick **Custom ending** in the prototype bar to start from a saved one and try changing it.
- Compare the six layouts of the sheet with **Version: Simple | Split | Tabs | Rows | Tiles | Jobs** in the prototype bar, or link one straight away. Simple is the default, so no parameter (or `?variant=simple`) gives Simple, `#/edit?variant=split` gives Split, `#/edit?variant=tabs` gives Tabs, `#/edit?variant=entry` gives Rows (QR Code, Social and Embed as rows, each opening its own page), `#/edit?variant=tiles` gives Tiles (three tiles side by side, each opening its own page) and `#/edit?variant=jobs` gives Jobs. The version and the Social layout stay with you when you move between Publish, the Share tab and Insights. Jobs splits the sheet by what you're trying to do. On top, getting responses fast: the link with Copy and a square QR code button next to it (it opens your form's code page), the preview card, then Embed on your website as a text link. Under it, one row, Track where responses come from ("Get a tagged link for each social and a QR code for each place, then compare them in Insights."), opens its own page: one line linking to Insights, then two tabs. Social has a tagged link per place (Copy link shows Copied and an alert at the bottom). QR codes has Your QR Code and the codes you made as rows with the QR code icon, name and ref, then Customize QR code and Add another code. Tap anywhere on a code's row to open its page; Download on the row just downloads. The footer is just Done. Every version has the same top: the link, Use custom domain, a small Link preview label over the card, and Customize preview. Everything else in the sheet, from the code's page to Add another code, works the same in all three. The bar stays usable while the sheet is open. **Simple** is the version I'd ship, so it's the default (`#/edit`). **Split** (`#/edit?variant=split`) shows how I'd add tracked links later. I made it because an extra QR code and an extra tagged link are the same thing: a ref added to the same link. In the sheet it has two tabs, Share and Embed, and opens on Share. On the full-width Share tab page there are no tabs: Share link and Embed sit one under the other, each with its title, 24px apart. Share has the link with Copy and the square QR code button next to it (Share, Copy and the QR code button on a phone), Use custom domain, the link preview and Customize preview, then one quiet row, See where responses come from, with "Add a link for each channel, then compare them in Insights." under it and a count once you've made some ("2 links, 1 code"). The QR code button opens your code's page: the code with its link line, Download, and the logo right under it. Embed has the same Standard, Popup and Full page choice as the other versions, the same short scrolling code box that follows your pick, then Copy code with Customize embed on its right, and no tracking. The row opens one page for every tagged link and code, under one line: "Each one opens the same form with its own tag, so Insights shows where responses came from." A tip sits right under it: "Or add `?ref=anything` to your link yourself." It has two sections, 24px apart, with labels like Link preview. Links has "Click one to copy its tagged link.", then the socials and Email as rows like the QR codes, whatever the Social layout: the mark with no tile, the name with its ref under it (like ?ref=whatsapp), and an outlined Copy the same size as Download ("LinkedIn link copied"). They have no ⋮, since a preset has nothing to remove, so Copy sits right at the end of the row and the name and ref take the rest of the width. Then your own links with the link icon, name and ref, Copy ("Newsletter link copied") and ⋮ Remove, then Add another link. QR codes has your codes as rows with the QR code icon, name and ref: the whole row opens the code's page, Download and ⋮ sit on the row, and the codes you made have Remove in ⋮. Then Add another code. Remove always comes with Undo in the alert: "Newsletter link removed. It still opens your form, but new responses won't be tagged." or "Poster code removed. Printed copies still open your form, but new responses won't be tagged." Both tabs stay as short as the Jobs overview or shorter, and the height eases when you switch tabs. I also made a second tracking view to compare with the two sections: **Tracking: Sections | List** in the prototype bar, or `&track=list` in the link (it works with `?variant=` and stays with you between screens). It's one list of every tracked source: the socials and Email with their own marks, your links with the link icon, and your codes with the QR code icon, each with its name, its ?ref= line and the same rows as the two sections: an outlined Copy or Download, and ⋮ where there is something to remove. All / Links / QR codes on top filters the list in place, and Add another link and Add another code under it follow the filter (All shows both). A code's row opens its page; a link's row copies its link, since a link has no page of its own. Copy, Download and ⋮ only do their own thing. And **Simple**, the default (`#/edit`, or `#/edit?variant=simple`), to keep to the brief of making sharing simpler. It has the same two tabs, Share and Embed, with everything about tracking taken out. On the Share tab page, like Split, Share link and Embed sit one below the other instead of as tabs. Share has the link with Copy and the square QR code button next to it, Use custom domain, the link preview and Customize preview. The QR code button opens your one code (tagged ?ref=qr) with its link line, Download, and the logo section (Pro) right under it. Embed is the same as in Split. There are no extra codes, no tracked links and no socials list, and the footer is just Done. Insights only shows what Simple has: Sources lists Your QR Code and Direct / None, and every other visit counts as Direct / None, so the totals stay the same. I also made three layouts for the social links, so I can compare them in any version: **Social: Rows | Icons | Strip** in the prototype bar, or `?social=icons` and `?social=strip` in the link (no parameter for Rows). Rows are the borderless rows with Copy link on the right, Icons is a wrapping grid of round buttons with a label under each, and Strip is one row of the same buttons that scrolls sideways. All three use the same tagged links, and Copy shows an alert at the bottom. In all three the social marks are drawn in the text colour on a light grey tile, never in brand colours, like Tally's own icons. Captures with `?capture=1`, and the changelog demo, leave both switches out.
- Switch the plan between Free and Pro in the prototype bar. On Free you can try a new link ending or a logo, but saving the ending or downloading a code with your logo asks you to upgrade.
- Switch the Publish state in the prototype bar to see republishing with and without responses.
- Follow the **Prototype Guide** card on each screen.
- Go to **Insights** and switch between the example states in the prototype bar.
- Try everything at phone width too.

The demo form uses Tally's default header, a plain off-white band with no cover image. The surrounding Tally UI is static on purpose. Only the share feature changes. Every number on the Insights tab is example data.

The visuals page has the changelog image, a poster, social images for LinkedIn and X, and a cover for the demo form. The changelog image and GIF show the current Share tab in Simple, my proposal: Share link with Copy and the QR code button, Use custom domain, the link preview, and Embed with no layout picked yet, with Your QR Code open on its own page with Download and the logo. The GIF copies the link, opens Your QR Code from the button next to Copy and downloads it, picks Standard in Embed so its code and Copy code open, copies the code, then goes to Insights, where Sources lists Your QR Code next to Direct / None. The changelog demo (`#/share?codes=main&demo=changelog`) opens on Simple, so the GIF can be recorded again. Every code in them really scans and is tagged with where it was seen. Editable, layered sources for the changelog, social and cover images are in `design-sources/`, ready to drop into Figma.

## Built with

Vite, React and TypeScript. `qrcode` for the codes (error correction level H, so a logo in the middle still scans), `jspdf` for vector PDFs and `html-to-image` for the PNG exports. Icons are Lucide, brand marks come from Simple Icons (drawn in the text colour), and the type is Inter, to stay close to Tally's own UI.

```bash
npm install
npm run dev      # local dev server
npm run build    # static build in dist/
```

The site deploys to GitHub Pages through `.github/workflows/pages.yml`.
